# results

Experiment outputs. Small CSV/JSON summaries are git-tracked; large logs are ignored.

Naming: `results/<step>_<experiment>_<date>/` with `summary.json` and per-round CSV logs. Final results go to `results/final/` with `key_numbers.json` (Step 09).

Every number used in the thesis, paper, poster, or website must come from a file in this folder and must also be recorded in `docs/EXPERIMENT_RESULTS_LOG.md`.
